# QA Portfolio

HUB — Index of quality assurance studies, projects, and related work.

## Portfolio Architecture

The portfolio is organized into eight repositories plus this hub. Each repository represents a phase of the QA learning path and contains the practical deliverables from that stage.

The repositories are built in the following order:

1. [qa-fundamentals-notes](https://github.com/felipezoltowski/qa-fundamentals-notes)  
   Phase 1 — notes, glossary, technique worksheets

2. [manual-testing-automationexercise](https://github.com/felipezoltowski/manual-testing-automationexercise)  
   Phase 2 — test plan, cases, bug reports, matrix

3. [api-testing-restful-booker](https://github.com/felipezoltowski/api-testing-restful-booker)  
   Phase 4 — Postman + Newman + contract tests

4. [playwright-e2e-framework](https://github.com/felipezoltowski/playwright-e2e-framework)  
   Phase 5 — FLAGSHIP. Pinned #2

5. [performance-testing-k6](https://github.com/felipezoltowski/performance-testing-k6)  
   Phase 6 — k6 + JMeter + Lighthouse

6. [security-a11y-testing](https://github.com/felipezoltowski/security-a11y-testing)  
   Phase 6 — ZAP, axe, WAVE, OWASP Top 10 write-ups

7. [mobile-automation-appium](https://github.com/felipezoltowski/mobile-automation-appium)  
   Phase 7 — Appium + Android emulator

8. [<you>/<you>](https://github.com/felipezoltowski/<you>)
